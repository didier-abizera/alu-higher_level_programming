# Python - Almost a Circle

This project covers unit testing, serialization, deserialization, and OOP in Python.

## Classes

### Base
Manages id attribute for all future classes.

### Rectangle
Inherits from Base. Represents a rectangle with width, height, x, y, and id.

### Square
Inherits from Rectangle. Represents a square with size, x, y, and id.

All classes are fully unit tested using the unittest module.
